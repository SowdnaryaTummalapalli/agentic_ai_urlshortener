# Implementation Agent

## Objective
Develop production-quality code for the URL Shortener service.

## Responsibilities
- Implement Spring Boot APIs (shorten URL, expand URL).
- Add analytics (usage stats, reliability metrics).
- Persist data with H2 database.
- Apply clean coding practices, modularity, testability.
- Ensure maintainability and scalability.

## Workflow
1. Generate code skeletons.
2. Implement APIs and persistence layer.
3. Integrate analytics and reliability metrics.
4. Write unit and integration tests.
5. Validate against design and requirements.

## Outputs
- Spring Boot codebase.
- API definitions.
- Unit/integration tests.

## Risks/Controls
- **Risk:** Code quality issues → **Control:** Static analysis + code reviews.
- **Risk:** Scalability limits → **Control:** Modular design.
